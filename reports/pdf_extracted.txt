1.2 Overall Accessibility Status 

This review confirms 2 Success Criteria failures out of the 56 assessed under WCAG 2.2 (a 3.6% 
failure rate), against 54 passes and 0 not-applicable criteria — every criterion was directly assessed 
against the homepage and the linked Contact page. Both confirmed failures are isolated to the same 
shared component: the site's chat widget. Its “BnB Support” heading (H3) appears in the DOM 
before the page's own H1 (“FOCUS on What Matters”), breaking a logical top-down heading 
hierarchy, and its close button measures roughly 14×24 CSS pixels, short of the 24×24 minimum 
target size. 

Everything else tested — non-text alternatives, colour contrast, keyboard operability, focus visibility, 
form labelling and error handling, reflow, ARIA semantics, and consistency across both pages — 
passed. WCAG 2.2 Level AA conformance is not yet fully met, but the site's overall pass rate (96.4%) 
reflects a strongly accessible implementation, and because both failures sit within the same shared 
chat widget, a single component-level fix is likely to resolve them across every page where it 
appears. Section 8 details each issue with recommended fixes.

8.1 Chat Widget Heading Appears Before the Page's Own H1 

STATUS 

WCAG 2.2 
REFERENCE 

DESCRIPTION 

OPEN 

1.3.1 Info and Relationships (Level A) 

The chat widget's “BnB Support” heading (H3) appears in the DOM before the page's 
own H1 (“FOCUS on What Matters”), breaking a logical top-down heading hierarchy. 

IMPACT ON USERS 

●  Screen-reader users navigating by heading level encounter the chat widget's 
H3 before the page's own H1, which is disorienting since the page's actual 
top-level heading should logically come first. 

AFFECTED URL 

https://bnbfin.com/ 

RECOMMENDATIONS 

●  Reorder the DOM so the page's own H1 (“FOCUS on What Matters”) 

appears before the chat widget's “BnB Support” heading, restoring a logical 
top-down hierarchy. Since the chat widget is a shared component, verify 
this fix across every page where it appears. 

8.2 Chat Window Close Button Below Minimum Target Size 

STATUS 

WCAG 2.2 
REFERENCE 

DESCRIPTION 

OPEN 

2.5.8 Target Size (Minimum) (Level AA) 

The chat widget's close button (“×”, aria-label “Close Chat Window”) measures about 
14×24 CSS px, under the 24×24 minimum. 

IMPACT ON USERS 

●  Users with limited dexterity or motor impairments, and touchscreen users 
generally, may find this narrow close button difficult to accurately activate. 

AFFECTED URL 

https://bnbfin.com/ 

RECOMMENDATIONS 

●  Enlarge the chat window's close button to at least 24×24 CSS px, either by 

increasing its width or adding sufficient padding/spacing around it. Since 
this is part of the shared chat widget component, a single fix should resolve 
it across every page where the widget appears. 

Remediation priority: both fail points sit within the shared chat widget component and are isolated, 
low-effort fixes relative to the site's otherwise strong accessibility performance. Priority should go to 
(1) reordering the DOM so the page's H1 appears before the chat widget's heading, and (2) enlarging 
the close button to at least 24×24 CSS px. A single fix to the shared chat widget component should 
resolve both findings across every page where it appears.
